EDGE CASES TO TEST
==========================================

1. Try registering with existing email
   - Expected: Error message "Email already exists"

2. Try login with wrong password
   - Expected: Error message "Invalid email or password"

3. Try accessing admin pages as buyer
   - Expected: Redirect to home page

4. Try accessing seller pages as buyer
   - Expected: Redirect to home page or error

5. Try adding to cart while not logged in
   - Expected: Redirect to login page

6. Try deleting user while viewing as that user
   - Expected: Error "Cannot delete your own account"

7. Try editing a product you don't own (seller)
   - Expected: Error or redirect

8. Try sending message to yourself
   - Expected: Error "Cannot message yourself"

9. Try checkout with empty cart
   - Expected: Error or redirect to cart

10. Try accessing order that belongs to different user
    - Expected: Error or redirect

SECURITY TESTING
==========================================

1. SQL Injection
   - Try searching: ' OR '1'='1
   - Expected: Treated as literal string (safe)

2. XSS Attempt
   - Try product title: <script>alert('xss')</script>
   - Expected: Displayed as text, not executed

3. Session Hijacking
   - Try cookie manipulation
   - Expected: Session validation fails

4. CSRF (Cross-Site Request Forgery)
   - Try form submissions from external site
   - Expected: Either fails or requires session validation

5. Unauthorized Access
   - Try direct URL access to admin/orders.php as buyer
   - Expected: Redirect to home page
